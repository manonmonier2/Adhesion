# Adhesion analysis
Workflow to perform the analysis of the adhesion data generated by @Manon Monier.

## Requirements

R version 4.1.2 (2021-11-01)

### R package

eadxl 1.3.1, cli 3.1.0, config 3.2, svglite 2.0.0, ggplot2 3.3.6, dplyr 1.0.8

## Script description
All the word between "[" "]" reference to a parameter in the _config.yml_ file.

## How to run scripts

Before running the scripts (in an IDE or command line), the configuration file [config.yml] must be modified according to your PC architecture. 
The [base_path] variable in line 4 should point to the "example" folder. (Note: If you modify this folder, the config.yml file must be updated accordingly).

## Script workflow

**_1_concatenation_batch.R_**

This script concatenates several result files with pupa ids, load, time and position values obtained from adhesion test software into a single file.

Input: all files (.xlsx) present in the **[batch/raw]** folder 
These .xlsx are obtained directly from the Nexigen software. In each of these .xlsx files, the first sheet contains pupae ids and their associated comments. Second sheet contains load, time and position values. First id in sheet 1 corresponds to the first three columns (load, time and position) in sheet 2. The second id corresponds to the following three columns in sheet 2 and so forth for the next ids. 

Output:
The merged files are returned in **[batch/concatenate/data_concatenate.csv]** for the load, time and position values and **[batch/concatenate/id_concatenate.csv]** for the id file.

No id correction is done at this stage.

**_3_load_data.R_**
This script creates individual files of load, time and position values for each pupa and recalibrates the force values at 0 at the beginning of the experiment.

Input:
In **[metadata]** directory : metadata_concatenate.csv obtained from 2_concatenation_metadata.R.
In **[batch/concatenate]** directory : data_concatenate.csv; id_concatenate.csv obtained from 1_concatenation_batch.R.

Output:
In **[batch/concatenate]** directory : File of errors encountered in the script (id_batches_error.log).
All files (.csv) in **[batch/batch_by_id]**. Individual file of load, time and position for each pupa.


From the concatenated batches file **[data_concatenate.csv]**, the corresponding id file **[id_concatenate.csv]**, and **[metadata_concatenate.csv]** the script creates an unique batch file per id (write in **[batch_by_id]**).

This id must be shared and unique in **[id_concatenate.csv]** and **[metadata_concatenate.csv]**.
Without this condition, we have no explicit link between batches and metadata.

This script recalibrates curves at axis y=0 using the first 20 values of each curve.

If sigma of noise is > 0.01 over the first 20 values, it means there is a peak in the first values. This can be due to an accident, a shoch on the machine, during the experiment. In this situation, we do not recalibrate.
If sigma of noise is < 0.01 there is no peak, we recalibrate the curve.


**_4_index_definition.R_**

This script defines 7 landmarks on single pupa curves. The curve is segmentated in six parts.

Input:
All files (.csv) in **[batch/batch_by_id]** obtained from 3_load_data.R.
**[Metadata/metadata_concatenate.csv]** obtained from 2_concatenation_metadata.R.

Output:
In **[index]** directory: Csv file containing landmarks determined for each pupa (index.csv). List of landmarks that could not be determined (index_id_not_running.log).


For each single pupa, we define the following values using their unique batch file found in **[batch_by_id]**:

sigma_1_temp = standard deviation of the force over the 20 first values of the experiment.

index_1 : corresponds to the moment at which the sensor comes into contact with the pupa. After index_1, the captor presses into the pupa until reaching a given force (0.07 N for standard protocol, or else 0.25 N). We use the curve portion from the beginning of the experiment until the curve reaches 3xsigma_1_temp for more than 3 seconds. Checking that the force goes above 3xsigma_1_temp for more than 3 seconds allows to eliminate spurious force peaks due to disruptive events such as a shock to the table. On this curve portion, index_1 is defined when the curve reaches sigma_1_temp for the first time.
In situations where sigma_1_temp was incorrectly estimated (the sensor touches the pupa before recording, shock to the machine, etc.), we were not able to define index_1 as above and considered that index_1 and index_2 colocalized.

noise_1: median of the force values comprised between the beginning of the experiment until index_1

index_2 : for pupae detached using the protocol '5min', index_2 is defined when the force is maximal. For other protocols, index_2 is reached when the extension is maximal.

index_3:  corresponds to the moment the sensor applies a smaller constant force (0.03 N in the standard protocol, or else 0.21N) for a given time (10 s in the standard protocol, else 0 or 5 min), from index_3 (first time the force is constant) to index_4 (end of the compression phase). In the situation where the time gap between index_2 and index_3 is longer than 1sec, index_3 is defined 0.5 seconds after index_2.

index_4 : corresponds to the end of the phase where a constant force is applied to the pupa. After index_4, the sensor goes up. For pupae detached using the protocol '5min', index_4 is defined 300 seconds after index_3. If the protocol '0s' is used, index_4 and index_3 colocalize. For other protocols, index_4 is defined 10 seconds after index_3.

noise_4 : amplitude of the force between index_3 and index_4.

amp_noise_6_temp : amplitude of the force over the last 50 values of the experiment.

index_5 : corresponds to the maximal negative force (the detachment force). We consider there is a peak of detachment force when the lowest force value in the entire experiment is lower than 3*amp_noise_6_temp.

index_6 : corresponds to the end of the experiment. It is defined as the last value.

noise_6: median of the force between index_5 and index_6.


**_5_interpolation.R_**

This script calculates the integral of the adhesion test curves obtained for each pupae.

Input:
All files (.csv) in **[batch/batch_by_id]** obtained from 3_load_data.R.
**[index/index.csv]** obtained from 4_index_definition.R.

Output:
In **[integral]**: File of integration results for each pupa (integral.csv). List of pupae for which we could not perform integration (integral_id_not_running.log). List of pupae for which the detachment pick is above 0N (log_file.txt).

The script separated the curve in three curves, the compression curve from index_1 to index_2, the positive and negative sections of the decompression curve from index_2 to index_5.
We interpolate and perform integration on the three curves.

The script saves the following values in **[integral/integral.csv]**:
integrale_compression = integration of the compression curve
integrale_decompression = integration of the whole decompression curve (negative + positive sections).
integrale_decompression_negative = integration of the negative section of the decompression curve.
integrale_decompression_positive = integration of the positive section of the decompression curve.
sum_decompression_negative_and_positive = sum of the integration of positive and negative sections of the decompression curves.
difference_integrales = difference between the integration of the compression and decompression curves.


**_6_prepare_data_figure.R_**

This script calculates adhesion properties and exports them in a text file.

Input:
All files (.csv) in **[batch/batch_by_id obtained]** from 3_load_data.R.
**[Metadata/metadata_concatenate.csv]** obtained from 2_concatenation_metadata.R.
**[Index/index.csv obtained]** from 4_index_definition.R.
**[Integral/integral.csv]** obtained from 5_interpolation.R.

Output:
In plot: concatenated file with pupae ids and their corresponding measurements of adhesion properties (data_figure.csv).

For all pupae, the following values are calculated:
detachment_force: the detachment force of the pupa is obtained as the minimal force value between index_4 and index_5.
energy: corresponds to integration of the compression and decompression curves.
negative_energy: corresponds to the integration of the negative section of the decompression curve.
rigidity: (index_2 force - index_1 force)/(index_2 position - index_1 position)
position_difference: corresponds to the deformation reversibility, is calculated as index_1 position - index_5 position
pression_extension: corresponds to the difference of position during pression on pupa, is calculated as index_2 position - index_1 position
pupa_area: corresponds to the pupa area in mm²
pupa_length: corresponds to the pupa length in mm
pupa_shape: calculated as pupa_length/sqrt(pupa_area)
pupa width: corresponds to the pupa height in mm
glue_area_mm: corresponds to the pupa glue area in mm²
detachment_force_div_glue_area: corresponds to the adhesion strength, calculated as detachment_force / glue_area_mm
glue_area_div_pupa_area: corresponds to glue investment, calculated as glue_area_mm / pupa_area

For each of these values, their corresponding value in log base 10 is calculated.



**_one_parameter_plot.R_**

This script creates boxplot graphs, tables and bar plot graphs.

Input:
All files (.csv) in **[batch/batch_by_id obtained]** from 3_load_data.R.
**[index/index.csv]** obtained from 4_index_definition.R.
**[integral/integral.csv]** obtained from 5_interpolation.R.
**[plot/data_figure.csv]** obtained from 6_prepare_data_figure.R.

Output:
In **[plot/one_parameter]**
Folder **[by_protocol_and_species]**: files of boxplots for each adhesion properties obtained for Drosophila melanogaster pupae tested with different protocols (.pdf).
Folder **[by_species]**: files of boxplots for each adhesion properties obtained for all species tested (.pdf).
Folder **[by_stock]**: files of boxplots for each adhesion properties obtained for several stocks tested (.pdf).
Folder **[normalisation]**: files of boxplots for each adhesion properties divided by the glue area for pupae detached after adhesion test (.pdf).
Folder **[normalisation_other_comments]**: files of boxplots for each adhesion properties divided by the glue area for pupae broken or not detached after adhesion test (.pdf).
Folder **[tables]**: table with number of pupae detached, broken or not detached per protocols used on Drosophila melanogaster (table_protocol_melano.csv).


The **FUNCTIONS** section of the script defines statistical functions shapiro, bartlett, anova, kruskal-walis, tukey and dunn tests used in the following. For all these tests, we used 0.01 as alpha level. If the shapiro and bartlett test conditions are met, we apply the tukey test as a post hoc test. Otherwise, Dunn test is used. 

The **one parameter plot** section of the script creates boxplot figures. 
The **D. melanogaster protocols** section creates the boxplot for pupae tested with different protocols for Drosophila melanogaster and saved in **[plot/one_parameter/by_protocol_and_species]**.
The **by species** section creates the boxplot for pupae from different species and saved in **[plot/one_parameter/by_species]**.
The **by stock** section creates the boxplot for pupae from different line stock and saved in **[plot/one_parameter/by_stock]**.
The **reduction graph force divided by glue area** section creates boxplots for adhesion strength parameters with a 5% reduction of the dataset, which removes very high values of the plot. In this graph, only pupae detached after the adhesion test are used. Saved in **[plot/one_parameter/normalisation]**.
The **normalisation by glue area - other comments** section creates boxplots for adhesion strength parameters with a 5% reduction of the dataset, which removes very high valuesof the plot. This graph is for pupae broken or not detached after adhesion test. Saved in **[plot/one_parameter/normalisation_other_comments]**.

The **STATS** section creates bar plots and tables of the number and percentages of tested pupae and is separated as follows. All plots are saved in **[plot/one_parameter/by_species]**.
The **graph scatter plot number of ok and not ok** is a scatter plot of the number of detached pupae versus the total number of tested pupae all species tested.
The **barplot comments percentage standard protocol** creates a barplot of the percentage of pupae detached, not detached and broken per species when tested with the standard protocol.
The **barplot comments percentage 1 strong tape ; glue ; 0.25 N protocol** creates a barplot of the percentage of pupae detached, not detached and broken per species when tested with the 1 strong tape ; glue ; 0.25 N protocol.
The **barplot percentage of pupae with null glue area** creates a barplot of the percentage of pupae with a glue area not null or null.
The **table melano comments** creates a table with the number of pupae detached, not detached or broken for Drosophila melanogaster pupae tested with different protocols.

**_phylogenetic_tree.R_**

This script makes the figure displaying medians of pupa shape, glue area, glue investment, detachment force and adhesion strength with a color gradient, for each species and their phylogeny topology is displayed. 


Input:
All files (.csv) in **[batch/batch_by_id]** obtained from 3_load_data.R.
**[index/index.csv]** obtained from 4_index_definition.R.
**[integral/integral.csv]** obtained from 5_interpolation.R.
**[plot/data_figure.csv obtained]** from 6_prepare_data_figure.R.

Output:
In **[plot/one_parameter/by_species]** : heatmap.pdf


The **data preparation** section selects the species, protocols and stocks used in the plot. For the adhesion parameter 'detachment_force_div_glue_area' corresponding to adhesion strenght, we remove 5% of the dataset which are very high values. For each species, we calculate the median of the adhesion parameters pupa shape, glue area, glue investment, detachment force and adhesion strength listed in 'parameter_list_tree'. Using the ggplot function, 'geom_tile' creates independant columns for each adhesion parameters with a color gradient scecified. The function 'new_scale_fill' creates a new scale for each adhesion parameter. The plot is saved in **[plot/one_parameter/by_species]**.

The section **arbre phylo** creates the newick format code for the phylogenetic tree arborescence. The tree is displayed using the function 'plot'.

Input:

Csv file,  made manually, of the average humidity preference index for each species studied in humidity preference experiments (humidity_experiments.csv). 

Output:
**[plot/ecology]**: files of scatter plots between ecological, humidity preference variables and adhesion properties for all species tested (.pdf).

It also creates a table containing the correlation coefficients r² between each couple of parameters. Plots and table are saved in **[plot/ecology]**. 

The **load ecology data** section imports daily meteorological data of 23 collection locations over 10 years (ecology_data.csv).
